# 중고거래 정보 재인 실험 — A/B 설문

- A집단: 일반 서술형 거래글
- B집단: 구조화된 상품 정보
- 거래글 열람 후 정보 재인 5문항, 분쟁 시나리오 후 책임 판단 8문항
- 모든 객관식/Likert 문항 필수 응답
- A/B는 Supabase RPC에서 현재 집단별 인원수를 고려해 균형 무작위 배정
- 참가자 응답 및 집단, 진행 단계, 재인 점수 저장 / 관리자 CSV 내보내기

## Supabase 설정
`config.js`에 이미 입력된 Project URL과 publishable key를 사용합니다. 실제 프로젝트의 SQL Editor에서 `schema.sql`을 실행해야 합니다. 기존에 이전 버전의 테이블/함수를 이미 실행했다면, 새 `schema.sql`을 다시 실행해 함수 정의를 갱신하세요. 새 조사 전에 기존 테스트 응답을 보존할지 반드시 확인하세요. 응답을 삭제하려면 연구 시작 전에만 `truncate table public.participants;`를 실행합니다.

## GitHub Pages
ZIP 안 `JJJJJJJJ-main` 폴더의 파일들을 저장소 최상위에 업로드하세요. Pages는 root 경로로 배포합니다.
- 참여자: `index.html`
- 관리자: `admin.html`

## Figma 자극물
참가자 화면에 다음 Figma embed URL을 A/B별로 표시합니다.
- A: `node-id=0-1`
- B: `node-id=3-1018`

Figma 파일의 공유 설정에서 임베드/링크 열람이 가능해야 합니다. 임베드된 디자인은 Figma의 원본 화면을 표시하므로, 실제 참여자 조사 전 반드시 화면 안의 상품명·이미지·문구가 최종 자극물과 일치하는지 확인하세요. 거래글 본문과 B의 구조화 정보는 설문 코드에서 제시한 연구용 문구를 사용합니다.

## 중요 확인사항
1. 현재 자극물 코드의 상품가격은 재인 문항 정답과 일치하도록 30,000원으로 설정했습니다.
2. 거래글은 2025년 9월 구매, 약 1년 사용, 사이즈 95(M), 소매/앞부분 사용감, 신설동역 직거래, 택배비 3,000원 추가로 구성했습니다.
3. 재인 문항 정답은 순서대로 ②, ③, ②, ③, ①입니다. 3번의 정답(주머니 부분 실밥)은 거래글/구조화 정보에서 확인되지 않는 항목으로 설정했습니다.
4. 분쟁 시나리오 및 책임 판단 8문항은 사용자가 제공한 문구로 구성했습니다. A/B 모두 동일한 분쟁 문구와 문항을 사용합니다.
5. 기존 DB에 남아 있는 예전 테스트 데이터는 새 설문 구조와 호환되지 않을 수 있습니다. 새 조사 시작 전 별도 백업 후 테스트 데이터 정리 여부를 결정하세요.
6. GitHub Pages의 정적 HTML과 Figma embed는 완전한 접근 차단 수단이 아닙니다. 참가자가 개발자 도구/브라우저 캐시 등으로 내용을 확인할 가능성은 있습니다.
7. 미성년자 대상 연구는 기관/지도교수 지침에 따른 보호자 동의, 연구 설명, 연락처, 개인정보/보존 기간 안내를 실제 배포 전에 반영해야 합니다.
